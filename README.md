# <p align="center">NixOS Gemstones</p>
***<p align = "center">My personal nixOS configurations<p>***

## <p align="center">Overview</p>
Gemstones is a nixOS 'config' that provides a base for creating configurations for multiple devices (hosts) quick

This setup includes various "modules" that provide installation and configuration templetes for programs, desktop environments, and utilities. Making it easy to quickly build a new config for a new device.
