# <p align="center">Simplix</p>
***<p align = "center">A Templete to create NixOS Configs<p>***

## <p align="center">Overview</p>
Simplix is a nixOS 'config' that provides a base for creating your own configurations for multiple devices (hosts)

This setup includes various "modules" that provide installation and configuration templetes for programs, desktop environments, and utilities. Making it easy to build your own personal NixOS config.
